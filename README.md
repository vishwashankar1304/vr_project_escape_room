# 🔓 VR Escape Room

Welcome to the **VR Escape Room**, an immersive virtual reality experience developed using Unity. This project places players in a richly detailed escape room where they must solve puzzles, find clues, and unlock their way to freedom—all within an interactive VR environment.

## 🎮 Features

- Fully immersive VR environment with room-scale interaction
- Puzzle mechanics (combination locks, hidden keys, object manipulation)
- Interactive items with physics-based grabbing
- Timer-based gameplay for added challenge
- Support for major VR headsets (Meta Quest, HTC Vive, Valve Index, etc.)
- Modular design for easily adding new rooms and puzzles

## 🛠️ Built With

- **Unity** (2022.3 LTS or later)
- **XR Interaction Toolkit**
- **OpenXR Plugin**
- **C#**
- **Blender** (for 3D assets, optional)
